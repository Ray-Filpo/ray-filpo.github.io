# ConsultAnythingTech

## Local Development

Run any static HTTP server from the project root:

```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx)
npx serve .
```

Open `http://localhost:8000` in your browser.

### Running Automated Verification Tests

```bash
python3 tests/test_structure.py
```
