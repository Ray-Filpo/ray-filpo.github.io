🖥️ Making Your First Backup

Open AOMEI-Backupper from your desktop shortcut. On the main screen you will see large tiles, each one representing a task. Look for the tile labeled for file backup and click it.

A new window opens with two sides. On the left, select the folders you want to protect. On the right, select the external drive or second disk that will hold the copy. If your external drive has not been plugged in yet, connect it now and press the refresh button so it appears in the list.

Give the backup a name you will recognize later, something like "Documents March" or "Photos 2024". Names make restoration easier when you have several backups saved over time.

Press the start button. A progress bar shows how much has been copied and roughly how long is left. You can minimize the window and keep using your computer. When the bar reaches the end, a confirmation message appears and the backup is finished.

Consider scheduling the same task to run once a week. The program can copy only the files that changed since the last run, so repeat backups finish much faster than the first one.

🧩 Disk and Partition Tools

Beyond backups, AOMEI-Backupper includes a full set of everyday disk tools. They are grouped on a separate screen and all of them follow the same pattern: choose a drive, choose an action, review a preview, then confirm.

The most used option is resize partition. If your system drive is nearly full while another drive has plenty of room, you can drag a slider to move space from one to the other. Another popular choice is merge partitions, which combines two neighboring drives into a single, larger one so you stop juggling drive letters.

The split partition tool does the opposite: it takes one large drive and divides it into two, which is handy when you want a separate area for work files. The OS migration wizard copies Windows from an older drive to a new one, and the partition recovery wizard scans a drive for lost volumes and lets you restore what it finds.

Every one of these actions shows a preview before anything is written to disk, so you can check the layout of your drives and cancel if something looks wrong. Nothing changes on your computer until you press the final confirm button.

🛟 Restoring Your Data

Restoration is the reverse of backup and takes only a moment to set up. Open the program and go to the restore screen. A list of the backups you created appears with the date and size of each one.

Select the backup you want. You can restore everything inside it, or open the backup like a folder and pick only a handful of files. The second option is useful when you deleted one document by accident but do not want to overwrite newer versions of everything else.

Choose a destination and press start. If you are restoring onto the original drive, the program asks for confirmation before replacing any file. Keep your external drive connected until the progress bar finishes and the completion message appears.
